# Field control baseline
Authorized administrators and managers can submit visits associated with an operator; auditors read only. Optional coordinates are collected explicitly through the browser or entered manually, stored as integer microdegrees. Observations are declarative, not proof of infringement. A server-side snapshot records up to 100 licenses at receipt time, not verified historical status at visit time. Client-generated UUIDs and canonical payload digests allow safe retries by the same agent; altered payloads are rejected. RLS and composite foreign keys enforce tenant scoping. The portal has a bounded volatile queue (50 entries) while the authenticated page remains open; session expiry, logout, module removal or reload discards it. This is not a durable offline-first PWA. No background tracking, attachment uploads, automatic sanctions, service worker, encrypted local storage or persistent synchronization. Future work: dedicated agent roles, encrypted offline storage and recovery, per-item conflict handling, verified location accuracy, evidence storage, retention/access policies and real device tests. GPS requires browser permission and secure context. No production deployment.
