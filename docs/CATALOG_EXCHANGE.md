# Rights360 catalog exchange v1
This proprietary JSON interchange format is not an official WIPO Connect, CISAC or DDEX standard. Exports are paginated (up to 100 artists or works per request) and omit contact details, internal UUIDs and financial data. Names remain personal data; share only with authorized recipients. Export artists before works to preserve member-number references. Both artists and works modules must be enabled; administrators, managers and auditors can export, administrators alone can import. Imports accept up to 100 artists and 100 works, default to dry run, report semantic conflicts with row numbers, and apply atomically only if valid. Existing identical records are skipped; conflicting records are never overwritten. New artists are pending and works draft. Rights shares, external identity mappings, CSV, attachments and official exchange adapters are not included. Export pagination is not a snapshot; concurrent edits outside the import lock can affect resolution. Formal data sharing agreements, provider specifications, stronger concurrent modification controls, request size limits, E2E and production review are required. No external transmission or production deployment.
