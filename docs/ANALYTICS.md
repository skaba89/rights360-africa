# Institutional analytics baseline
The analytics module provides cumulative operational counts from live PostgreSQL data for artists, works, operators/licenses, field visits and media observations. Finance metrics aggregate billed, declared received, outstanding and overdue amounts by currency; receipts are preaggregated per invoice to avoid join fanout. Royalty totals report gross, commissions and net calculations, not actual transfers. Currency amounts remain exact decimal strings in minor units, never summed across currencies. Only sections whose source modules are effectively enabled and entitled are exposed, with tenant RLS and read permission. No external BI warehouse or AI is included. The endpoint uses successive READ COMMITTED queries, not a single repeatable-read snapshot. Date filters, time series, exports, graphical dashboards, load testing, independent reconciliation and browser E2E remain outstanding. No production deployment.
