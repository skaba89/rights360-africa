# DSIG Control Center
The existing /portal now exposes a platform console only after successful server-side platform identity verification. Uses the authenticated in-memory token and existing APIs for paginated organization listing, creation, suspension/reactivation, module grants with optional expiry, and first administrator invitations. Invitation codes are displayed temporarily; no email is automatically sent. No artificial customer data is included. Backend authorization remains mandatory for each action. Static route and wiring tests are included; browser end-to-end testing, audit viewing, collaborator console, subscription billing, independent security review and deployment remain outstanding.
