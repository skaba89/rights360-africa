# Artist registry
The artists module provides organization-scoped records, member numbers unique within an institution, legal/stage names, optional contacts, and pending/active/suspended/archived status. Administrators and managers can create and update records; auditors can read. Artist accounts cannot view the institutional registry. Every request checks active commercial entitlement and tenant module activation, using RLS-scoped transactions. Changes record actor, resource and status in the audit trail; hard deletion is not exposed. The portal includes search, filters, pagination and editing. Member numbers are manually assigned; account-to-artist linking, identity verification, contracts, supporting documents, full field-level audit history, privacy retention and browser E2E remain outstanding. No actual customer data or production authorization.
