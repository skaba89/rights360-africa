Module availability requires both a DSIG grant (not expired) and the tenant's enabled preference. Default is denied, including existing tenants until explicitly granted. DSIG can grant or revoke each module and optionally set an expiry. A tenant cannot write entitlement rows. Revocation or expiry masks the saved preference; renewing a grant restores that preference. Future business endpoints must enforce effective entitlement on every request; the current phase covers module configuration and listing only. Billing, plan catalog, payment automation, concurrent operation hardening and independent review are outstanding.
