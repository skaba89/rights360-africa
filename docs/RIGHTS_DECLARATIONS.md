# Rights declarations
Works can have versioned declarations of author, composer, publisher, beneficiary and other shares, expressed as integer basis points (100 = 1%). Draft totals cannot exceed 100%; complete declarations must equal 100%. The API locks the work row and checks the expected version before creating a new declaration. Existing declaration rows are not updated or deleted through the API. Composite foreign keys and RLS restrict associations to the same institution. Deferred database triggers verify totals at commit. Runtime insert privileges alone are not a guarantee of immutable history against a compromised database role: future hardening should seal declarations and serialize all direct SQL share inserts. A complete declaration is arithmetically complete, not legal approval or authorization to pay. Beneficiaries currently reference artist registry records; corporate rightsholders, territorial and temporal rights, disputes, approvals, separate rights categories and evidence are outstanding. Portal supports history and new versions with UUID entry. Browser E2E and production review remain outstanding.
