# Royalty distribution baseline
An institutional administrator can record an internal calculation for a single declared receipt tied to a single work. An explicit complete declaration for that work is required. The receipt may only be distributed once. Commission is entered in basis points, rounded half-up; the remaining amount is allocated using largest remainder and a deterministic UUID/role tie-break. Integer minor units preserve exact totals. RLS, composite foreign keys, append-only runtime privileges and deferred aggregate checks apply. A calculation is neither legal approval nor authorization to pay: receipts are unverified manual entries, commission limits are not yet institution-approved, and historical declaration selection is explicit rather than based on effective dates. No blanket-license allocation, repertoire matching, dispute resolution, reversals, independent approval, tax withholding, payment or browser E2E. These must be addressed before actual financial use. No production deployment.
