# Experimental acoustic comparison
The algorithm compares sequences of normalized Goertzel spectral-band energies from mono PCM16 WAV at 8 kHz, 3–30 seconds. Reference registration requires an administrator and a registered musical work. Media and works entitlements apply. Raw WAV is processed in memory, not persisted by the application; reference signatures and exact-file SHA-256 hashes are stored under tenant RLS. Matching ranks up to 20 reference excerpts and returns the top five similarities; scores are not probabilities or verified identifications, and low-score candidates may be returned. This is a limited spectral baseline, not a robust commercial music fingerprinting service. It is sensitive to pitch, tempo, mixtures, noise and sparse bands; synthetic tone tests do not establish real-world accuracy. No automatic billing, audio streaming, external provider, machine learning or legal determination. Only use authorized excerpts. Before wider use, add reference revocation, recording-level IDs, calibrated rejection thresholds, representative licensed evaluation corpus, precision/recall measurements, request rate and CPU limits, indexed matching, retention policy and browser E2E. No production deployment.
