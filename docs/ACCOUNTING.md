# Auxiliary accounting journal
Administrators manually post source events in order: invoice, receipt, distribution. The application generates balanced debit/credit lines with exact integer minor units, unique source posting, tenant isolation, and deferred database balance checks. Technical accounts are receivable, royalties_unallocated, cash_unverified, management_commission and beneficiary_payable (with artist dimension). Receipts are not bank-verified and distributions are not legally approved. Read-only journal and account balances are available per currency. This is not a certified SYSCOHADA ledger: chart mapping, opening balances, fiscal periods, closing, reversals, reconciliation, independent approvals, taxes, financial statements and statutory exports remain outstanding. Direct database insert privileges require additional hardening for immutable source consistency. No production use or real payment is authorized. Browser E2E and concurrency/load validation remain outstanding.
