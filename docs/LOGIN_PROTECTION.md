# Login protection
A database-backed fixed minute window limits account attempts (10) and immediate peer attempts (100), across application workers. Reservations commit before password checking, including failures. No forwarded header is trusted. Behind a proxy, the peer bucket may be shared by all users; configure a trusted proxy and edge limits before deployment. This is not a full distributed abuse prevention solution. Schedule deletion of expired buckets and monitor storage before production. Account bucket hashes are pseudonymous, not anonymous. MFA and recovery remain outstanding.
