# First customer administrator
An authorized DSIG platform administrator can issue an invitation for an active organization without an existing administrator or platform grant. The invitation is valid for 24 hours, replaces previous pending invitations, and stores only a SHA-256 digest of a 384-bit random token. Deliver the token privately to the verified recipient; automatic email delivery is not implemented. Acceptance creates a new account and an admin membership atomically, with an Argon2id password chosen by the recipient. Existing accounts are not linked or overwritten. The recipient must enroll MFA before accessing business endpoints. Audit events record issuance and acceptance. No credentials should be logged. Before production: implement recipient verification, secure delivery, explicit revocation, retention, privileged step-up authentication, rate-limit tuning and independent security review. Suspension prevents acceptance while inactive; unused invitations may become valid again on reactivation until expiry.
