Platform administrators can list, create, suspend and activate customer organizations. Narrow SECURITY DEFINER functions check the session and platform grant on each call; direct cross-tenant table access remains denied. Suspending an organization deletes its sessions and blocks authentication; reactivation does not restore sessions. The organization hosting an active platform administrator cannot be changed by this endpoint. Mutations record actor, target, action and timestamp in a separate audit table. Customer account provisioning, invitations, subscriptions, privileged step-up authentication, audit viewing and independent review of privileged SQL functions remain required before production.
